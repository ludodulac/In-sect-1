# Machine Shorts Piano 3D

## Règle de base
Une vidéo = une idée = un problème ou un désir clair.

## Structure universelle
1. **Hook (0–3 s)** : problème, surprise ou résultat.
2. **Preuve (3–8 s)** : jouer / montrer immédiatement.
3. **Explication (8–25 s)** : une seule idée.
4. **Exercice ou transformation (25–40 s)** : action concrète.
5. **Résultat (40–50 s)** : rejouer ou comparer.
6. **CTA éventuel (50–55 s)** : inviter à montrer son problème.

## Boucle de production
1. Pendant les coachings, noter les blocages intéressants.
2. Une fois par semaine, sélectionner 3 à 5 problèmes.
3. Écrire uniquement les hooks et l'idée centrale.
4. Tourner en batch.
5. Monter avec un gabarit récurrent.
6. Publier la même création sur Shorts, Reels et TikTok.
7. Mesurer les conversations et ventes, pas seulement les vues.

## Principe inspiré de Brieuc Le Dantec
Copier la **simplicité opérationnelle**, pas sa personnalité ni sa mission : formats reconnaissables, un concept par vidéo, résultat visible, progression accessible.
